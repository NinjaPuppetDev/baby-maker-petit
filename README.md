# Baby Maker Petit — Stage 1: Art Direction & Digital Gallery

Baby Maker Petit is the artistic practice of Melissa Rosales, a professional artist specializing in hyperrealistic baby sculpture and transitional platinum silicone art.

## Visual Identity & Design System
- **Positioning**: Hyperrealism × Craft × Fantasy × Emotion × Technology
- **Aesthetic**: Warm Editorial × Luxury Atelier × Enchanted Digital Gallery
- **Palette**:
  - Warm Ivory (`#FAF7F2`)
  - Soft Cream (`#F3ECE4`)
  - Warm White (`#FFFFFF`)
  - Deep Warm Charcoal (`#201D1B`)
  - Warm Taupe (`#8E847A`)
  - Baby Maker Peach Accent (`#E29578`)
- **Typography**:
  - Editorial Serif: Cormorant Garamond
  - Contemporary Sans: Plus Jakarta Sans
- **Bilingual Support**: English & Spanish (client-side toggle with persistent storage)

## Core Gallery Experience
- **Home**: Opening atmosphere, philosophy statement, selected works, atelier glance, artist note, world teaser.
- **Work (`/work`)**: Artwork archive with series filtering, asymmetric editorial layout, and structured metadata.
- **Creation Details (`/work/[slug]`)**: Immersive photographic presentation, macro details, artistic narrative, craft notes, provenance specifications, and Certificate of Authenticity.
- **Atelier (`/atelier`)**: Six chapters of craftsmanship (The Medium, Translucent Skin, The Gaze, Micro-Rooting, Weight & Posture, Finishing & Provenance) and the silicone transition horizon.
- **Artist (`/artist`)**: Melissa's studio practice, background, philosophy, and hand-signed Certificate of Authenticity.
- **World (`/world`)**: Exploratory frontiers (Original Silicone Sculpture, Fantasy & Mythic Characters, Interactive Presence & Animatronics, Artificial Intelligence & Synthetic Emotion).
- **Archive (`/archive`)**: Chronological retrospective of works and milestones since 2020.
- **Contact (`/contact`)**: Bespoke commission inquiry, acquisition request, and studio communication channel.

## Tech Stack
- **Framework**: Next.js 16 (App Router) + React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Design Tokens
- **Icons**: Lucide React + Bespoke Brand SVGs
- **Package Manager**: pnpm

## Getting Started
```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build production bundle
pnpm build

# Start production server
pnpm start
```
